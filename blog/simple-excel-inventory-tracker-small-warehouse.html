Simple Excel Inventory Tracker for a Small Warehouse

3 October 2026

Small warehouses and early e-commerce shops rarely need an enterprise WMS on day one. They need a single workbook that answers: What do we have? What is on order? What is about to run out? What moved this week?

Excel (or LibreOffice / Google Sheets with care) is still a sane starting point when you have dozens to a few thousand SKUs, one or two people updating stock, and no appetite for monthly SaaS fees yet. This guide covers what to put in a simple tracker, how to avoid common spreadsheet disasters, and when a ready-made pack saves time.

Who this approach is for

  • Small warehouse or stockroom with a manageable SKU list
  • Online sellers using spreadsheets or bank exports instead of a full OMS
  • Teams that want no macros (easier to trust, easier to open on locked-down PCs)
  • Operators who will update the file a few times per week, not real-time multi-user chaos

Not ideal as a forever system: multi-warehouse networks, barcode-heavy high-velocity pick faces, or ten people editing the same file simultaneously. Plan to graduate later; do not pretend Excel is infinite.

Core sheets every simple tracker needs

1. Inventory (SKU master + on-hand)

Minimum columns:

Column Why
SKU / Item ID Stable key—never reuse casually
Name / description Human label
Location (bin/shelf) Speeds physical counts
On hand Current quantity
Reorder point Alert threshold
Reorder qty Suggested purchase quantity
Unit cost (optional) For inventory value
Notes Supplier quirks, fragile, etc.

Rule: one row per SKU. Variants (size/colour) get their own SKUs if you pick them separately.

2. Orders (inbound or customer—pick one primary)

Many small ops start with purchase / inbound orders or sales orders. Mixing both in one messy tab causes pain. Prefer:

  • Orders sheet: order ID, date, type (in/out), SKU, qty, status (open/received/shipped), counterparty
  • Or separate Purchases and Sales sheets with the same column logic

Update On hand when status becomes received or shipped. If you are not ready for transactional stock movements, do a weekly physical count and overwrite on-hand carefully—document the date of the count.

3. Reorder alerts

Two simple patterns (no macros required):

  • A column Needs reorder? with a formula: =IF(OnHand<=ReorderPoint,"YES","")
  • A filter view or separate Alerts sheet that lists only YES rows (FILTER in modern Excel, or AutoFilter)

Review alerts on a fixed weekday. Alerts you ignore are decoration.

4. KPI dashboard (one screen)

Keep KPIs few:

  • Total SKUs
  • SKUs below reorder point (count of YES)
  • Inventory value (if you track cost): SUM(OnHand * UnitCost)
  • Open orders count
  • Units received / shipped this week (if you log movements)

Charts are optional. A clean summary table beats a 3D pie chart.

How to set reorder points without overthinking

Start crude, then refine:

  1. List items that stocked out in the last 90 days.
  2. Set reorder point ≈ typical weekly usage × lead time in weeks, plus a small buffer.
  3. For slow movers, use a fixed minimum (e.g. 2–5 units) instead of a fancy formula.
  4. Review reorder points monthly for your top 20 SKUs only.

You are aiming for fewer emergencies, not perfect EOQ math.

Operating rhythm that keeps the file honest

Cadence Action
Daily (busy season) Log shipments/receipts the same day
2–3× per week Update open order statuses
Weekly Filter reorder alerts; raise POs
Monthly Spot-count top SKUs; fix location typos
Quarterly Archive old order rows to an Archive sheet

Single-writer rule: one person “owns” the file at a time, or use OneDrive/SharePoint co-authoring carefully. Emailing Inventory_FINAL_v7.xlsx to five people is how truth dies.

Mistakes that break spreadsheet inventory

  1. Editing on-hand without a reason — always note count date or movement.
  2. Duplicate SKUs with slightly different spellings.
  3. Merged cells in data tables — they break filters and formulas.
  4. Macros from unknown sources — security and IT blocks; prefer formula-only packs.
  5. No backup — keep dated copies or version history.
  6. Using the tracker as a CRM — customers and marketing notes belong elsewhere.

Build vs buy a template

Build if you enjoy spreadsheet design and have a weekend. Use Tables (Ctrl+T), data validation for status lists, and conditional formatting for YES alerts.

Migration checklist (from sticky notes / chat logs)

  1. Export or type a clean SKU list.
  2. Do one physical count; enter on-hand.
  3. Set reorder points for the top 20% of SKUs first.
  4. Enter open POs and open customer orders.
  5. Train the second person who might edit the file.
  6. Put the file path and “owner” name in a README tab.

When to graduate from Excel

Consider dedicated tools when:

  • Two+ people need simultaneous reliable edits all day
  • You need barcode scanning at speed
  • Channel stock (Shopify, Amazon, etc.) must sync automatically
  • Audit trails and permissions become mandatory

Until then, a disciplined workbook is a legitimate system.
